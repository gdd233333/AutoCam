AutoCam 取景器模型结构脑图

MNv4-Conv-S 学生 · CLIP / 显著性教师离卡 · 几何只在 C++ guide_from_box

ViewfinderNet 输入 preview_rgb [1,256,256,3] float 0–1 letterbox pad 114
输出 box[1,4] · obj[1,1] · logits[1,8]
1.27M params · 无 mask · 无 guide MLP

1. 数据

  • synthetic 色块矩形 随时可训
  • CADB 9,497 13+none 类 → 8 类
  • PICD 36k–49k 24 类折叠
  • 自有静物文件夹
  • prepare.py → index.jsonl

2. 教师（离卡 npz）

  • CLIP-ViT-B/32 8 类 zero-shot
  • v0 显著性 box center-surround + Sobel
  • CADB 元素框优先
  • U2-Net / YOLO-World 可选未接
  • λ_kd = 0，学生不学 mask

3. 骨干 MNv4-Conv-S

  • stem conv 3×3 s2 → 32
  • conv_bn 堆到 64 / 96
  • UIB ExtraDW / IB / ConvNeXt-style
  • 全程 ReLU，禁止 PReLU / attention
  • 末层 1×1 → 960 · GAP

4. 三个头

  • box FC 960→4 sigmoid cxcywh
  • obj FC 960→1 sigmoid
  • cls FC 960→8 原始 logits
  • 8 类：thirds center diagonal triangle leading_line symmetric fill_frame none

5. 损失与训练

  • L = 2.0 SmoothL1(box) + 1.0 wCE(cls)
  • 可选 BCE(obj)
  • AdamW 3e-4 cosine · AMP
  • batch 16 累积 4 = 64 · 12 GB
  • 教师与学生不同时占卡

6. 导出 / 端侧

  • FP16 tflite → LiteRT GPU
  • INT8 tflite float I/O → XNNPACK
  • opcode 白名单 CONV/DW/ADD/RELU/FC/MEAN…
  • InferenceRuntime 未接取景器
  • neural 失败必须回 rule

数据流：YUV/JPEG → letterbox 256 → 教师 npz 或合成 → ViewfinderNet → box+class → C++ guide_from_box → 引导叠层
